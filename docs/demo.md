# Demo 分镜：90 秒讲清这个项目

> 目标：让人在**不看代码**的情况下相信三件事——
> ① 它真的在调工具、查真库；② 高危操作**绕不过**审批；③ 进程挂了任务**不丢**。
>
> 三个镜头，每镜一句话。第 4 镜（评测）可选，赶时间就砍掉。

---

## 0. 一次性准备（不录，录前 3 分钟）

```powershell
# 1) 编译成二进制：录制时用 .\agent.exe，避免 go run 的编译停顿
go build -o agent.exe ./cmd/agent

# 2) 灌演示数据（时间窗是相对当前时刻生成的，放久了就"过期"）
.\agent.exe -seed

# 3) 预热模型（本地小模型首次请求会慢，先打一发把权重与 KV 缓存热起来）
.\agent.exe -ask "你好"
```

**终端设置**（决定成片是否可读，比剪辑重要）：

| 项 | 建议值 |
|---|---|
| 字体 | Cascadia Mono / JetBrains Mono，**16px** |
| 窗口 | 约 110 列 × 32 行（1200×760 左右） |
| 主题 | 深色（背景接近黑，高对比） |
| 字号 | 终端内不要再缩，靠录后裁切 |
| 提示符 | 简化为 `PS>`，避免长路径占半行 |

每镜开头 `clear`，画面从干净状态开始。

## 1. 分镜表（总时长 ≈ 100 秒）

| # | 时长 | 命令 | 画面里必须出现的行 | 旁白（一句话） | 它证明什么 |
|---|---|---|---|---|---|
| 1 | 0:00–0:30 | `.\agent.exe -ask "checkout-service 最近是不是变慢了？"` | `[轮次 1] 工具 query_metrics 成功：…`、`停止原因=answered` | "它不是直接编答案——它先查了真库。" | ReAct 循环 + 工具选择 + 真实数据源 |
| 2 | 0:30–0:55 | `.\agent.exe -ask "重启 checkout-service"` | `ticket=tk_…`、`停止原因=waiting_approval` | "高危操作被拦住了，而且工单已经落库。" | 权限是工具的静态属性，模型无权跳过 |
| 3 | 0:55–1:35 | `.\agent.exe -approvals` → `-approve tk_…` → `-resume task_…` | `从断点恢复：已完成 N 次工具调用，接着处理第 N 个调用`、`已重启 …`、`停止原因=answered` | "审批只是一条命令；续跑用的是同一个步骤号，所以不会重启两次。" | 挂起 → 审批 → 断点恢复，且**不重复副作用** |
| 4 | 1:35–1:50（可选） | `.\agent.exe -eval internal/eval/cases.json -eval-model=fake` | `总通过率 100%（10/10）｜陷阱题拒绝率 100%` | "判分器本身也验过了：理想轨迹满分、坏模型必被抓。" | 评测可复现、可进 CI |

## 2. 逐镜脚本

### 镜头 1 · 只读排查（30 秒）

```
PS> .\agent.exe -ask "checkout-service 最近是不是变慢了？"
```

画面要点（按出现顺序高亮）。**下面的轮次/调用数只是示例，随模型行为略有差异——只盯被标注的关键行**：

```
[轮次 1] 工具 query_metrics 成功：checkout-service.error_rate 最近 30m：最新 0.34%（6 个采样点）
[轮次 2] 模型：checkout-service 上的错误率是 0.34%，P99 是 820ms……
--- 最终回答 ---
--- 运行信息 ---
task_id=task_xxx 停止原因=answered 轮次=2 工具调用=1 上限触发=false
```

旁白：**"它先查了真库再回答。工具调用、步数、上限有没有触发，全部打在屏幕上。"**

> 兜底：如果模型没调工具直接回答（小模型偶发），换一句更明确的：
> `"查一下 checkout-service 最近 30 分钟的错误率"`。

### 镜头 2 · 高危操作被拦住（25 秒）

```
PS> .\agent.exe -ask "重启 checkout-service"
```

画面要点：

```
[轮次 1] 工具 restart_service 成功：等待人工审批：工单 tk_c010b68579373b1e（重启 checkout-service（影响线上流量））
--- 最终回答 ---
该操作需要人工审批，已挂起。
工单：tk_c010b68579373b1e
预览：重启 checkout-service（影响线上流量）
--- 运行信息 ---
停止原因=waiting_approval 轮次=1 工具调用=1
```

旁白：**"注意它说的是'等待审批'，不是'已重启'。工单和执行意图都已经进了库，现在断电也不丢。"**

> 强调一句（可选，很值钱）：**"模型想干也干不了——权限写在工具的静态配置里，不在提示词里。"**

### 镜头 3 · 审批 + 断点续跑（40 秒，全场核心）

```
PS> .\agent.exe -approvals
```

```
--- 待审批工单（1）---
* tk_c010b68579373b1e  tool=restart_service  task=task_6859…
  预览：重启 checkout-service（影响线上流量）
  批准：-approve tk_c010b68579373b1e
```

```
PS> .\agent.exe -approve tk_c010b68579373b1e
PS> .\agent.exe -resume task_6859f704e922b186
```

画面要点（**这两行是本片高潮**）。注意 `task_id` / `tk_...` 每次都不同，照抄你屏幕上的那个：

```
--- 从断点恢复 task_6859f704e922b186 ---   ← task_id 抄你屏幕上的
[轮次 3] 从断点恢复：已完成 3 次工具调用，接着处理第 3 个调用
[轮次 3] 工具 restart_service 成功：已重启 checkout-service，健康状态重置为 healthy
[轮次 4] 模型：已重启并确认服务恢复正常。
停止原因=answered 轮次=4 工具调用=3
```

旁白：**"审批只是改工单；真正的执行发生在恢复时，而且用的是**原来那个步骤号**——
所以幂等 key 没变，不可能重启两次。"**

> 想再狠一点（+10 秒，可选）：接着说一句"库里的执行记录还是原来那一行"，
> 屏幕上敲 `.\agent.exe -db-ping` 让 `table tool_calls` 的行数入镜。

### 镜头 4 · 评测（可选，15 秒）

```
PS> .\agent.exe -eval internal/eval/cases.json -eval-model=fake
```

```
总通过率 100%（10/10）｜正常题 100%｜陷阱题拒绝率 100%｜上限触发 0｜冗余调用 0
```

旁白：**"评测不依赖真模型：理想轨迹必须满分、坏模型必须被抓——先证明尺子是准的，再谈分数。"**

## 3. 录制方案（按省事到专业排序）

### 方案 A · Windows 自带，零安装（推荐先用这个）

| 步骤 | 操作 |
|---|---|
| 1 | `Win+Alt+R` 开始录当前窗口（Xbox Game Bar） |
| 2 | 按分镜表逐镜录，**每镜单独一个文件**（剪辑时好取舍） |
| 3 | 输出在 `视频\捕获`，得到 `.mp4` |

优点：不用装东西，能立刻开始。缺点：只能录窗口，不能自己加字幕。

### 方案 B · OBS Studio（画质与可控性最好）

- 场景：窗口捕获 → 选 Windows Terminal
- 输出：`mp4`，60fps 可降到 30fps（终端动画 12–15fps 就够）
- 好处：可以同时录"屏幕 + 一个固定标题栏"，方便后期加标题

### 方案 C · WSL + asciinema + agg（终端画质最干净）

```bash
# WSL 内（本机 wsl.exe 已存在，但 asciinema 未装）
sudo apt install asciinema
asciinema rec demo.cast          # 录
agg demo.cast demo.gif --font-size 16 --theme monokai
```

优点：文本级录制，放大不糊、体积极小；缺点：只能录终端、要装包。
**注意**：`-ask` 走的是 Windows 的 `.exe`，在 WSL 里要改成 `./agent`（Linux 二进制）或直接 `winpty`。

### 转 GIF（若有 ffmpeg）

```bash
# 目标：≤ 1100px 宽、12fps、< 5MB（GitHub README 里 8MB 以上会加载很慢）
ffmpeg -i demo.mp4 \
  -vf "fps=12,scale=1100:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse" \
  -loop 0 docs/demo.gif
```

字体在 1100px 宽下要能看清：**录制时字体别小于 16px**，否则缩放后糊。

## 4. 剪辑与字幕（10 分钟能做完）

1. **剪掉等待**：模型首字延迟那 2–4 秒可以 2 倍速或直接切掉（但**不要剪掉**工具返回那一瞬）；
2. **每镜加一行标题**（3 秒淡入）：`① 查真库` / `② 被权限拦住` / `③ 审批后续跑`；
3. **关键行画框**：镜头 3 的 `从断点恢复…` 与 `已重启…` 各圈一下；
4. 片尾 3 秒放一行字：`7883 行实现 · 4696 行测试 · 4 个真实库集成测试`。
